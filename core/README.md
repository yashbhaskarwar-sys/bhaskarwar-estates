# core/

**Purpose:** Foundational institutional documents.

This directory holds the governing documents that define what Bhaskarwar Estates is, how it operates, and what principles guide it.

## Contents (to be created)

| File | Purpose |
|------|---------|
| `GOVERNANCE.md` | Ownership structure, decision rights, governance rules |
| `PRINCIPLES.md` | Operating principles and non-negotiables |
| `MISSION.md` | Long-term mission and strategic intent |

## Philosophy

These documents change rarely and deliberately. Every change requires conscious decision, not convenience.

Do not store operational records here — those belong in `operations/`.
Do not store parcel or tenant data here — those have their own directories.
