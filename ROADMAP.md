# Roadmap — Bhaskarwar Estates

> A phased development plan. Strategic, not speculative. Update as phases complete.

---

## Phase 1 — Foundation *(Current)*

**Goal:** Establish operational infrastructure and institutional clarity.

- [x] Public teaser site launched (bhaskarwar.co.in)
- [x] GitHub repository initialized
- [x] Operational directory structure created
- [ ] Parcel documentation commenced
- [ ] Tenant pipeline formalized
- [ ] Core governance documents written
- [ ] Decision log started

**Exit criteria:** Parcels documented, tenant pipeline tracked, operations documented.

---

## Phase 2 — Parcel Development

**Goal:** Active development on anchor parcels.

- [ ] Survey and title verification complete for priority parcels
- [ ] Development brief written for each parcel
- [ ] Anchor tenant negotiations initiated
- [ ] Construction or fit-out planning begun

**Exit criteria:** At least one parcel under active development.

---

## Phase 3 — First Tenant Activation

**Goal:** First lease signed and tenant operational.

- [ ] First commercial tenant agreement executed
- [ ] Premises handed over
- [ ] Lease management system in place
- [ ] Operations rhythm established

**Exit criteria:** Revenue-generating tenancy operational.

---

## Phase 4 — Portfolio Expansion

**Goal:** Systematic expansion across Wani and Yavatmal region.

- [ ] Second parcel acquisition or development
- [ ] Portfolio reporting established
- [ ] Institutional documentation mature

---

## What Is Not in This Roadmap

- SaaS products
- Proptech platforms
- Speculative technology builds
- Consumer-facing apps

Technology appears in this roadmap only when it directly serves an operational milestone.
