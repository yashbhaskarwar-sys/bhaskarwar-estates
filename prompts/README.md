# prompts/

**Purpose:** Operational AI prompts and context templates.

This directory holds reusable AI prompts and context files used to assist in Bhaskarwar Estates operations. These are tools to accelerate institutional work — not to replace judgment.

## What Goes Here

- Context-setting prompts (e.g., bootstrapping a new conversation about parcels or tenants)
- Document drafting templates
- Analysis prompts for operational questions
- Review checklists in prompt form

## Philosophy

Prompts here are institutional assets. They should:
- Be clear, specific, and operational
- Reference MASTER_CONTEXT.md for estate context
- Avoid speculation or overreach
- Be maintained as the business evolves

## Usage

Reference these prompts when starting AI-assisted work on estate operations. Update them when the operational context changes significantly.
