# operations/

**Purpose:** Day-to-day operational records and standard operating procedures.

This directory holds the living operational layer of Bhaskarwar Estates — how things are done, what happened, and what needs to happen.

## Contents

| Subdirectory / File | Purpose |
|---------------------|---------|
| `sops/` | Standard operating procedures |
| `financial/` | Financial summaries and tracking |
| `maintenance/` | Maintenance logs and schedules |
| `reports/` | Periodic operational reports |

## SOPs

Standard operating procedures document repeatable processes:
- Tenant onboarding
- Lease renewal process
- Maintenance escalation
- Document filing discipline

## Philosophy

- Record what happened, not just what was planned
- Keep SOPs short — one page where possible
- Update records promptly; don't let them lag
- No speculative documentation — only document real processes
