### 2026-05 — Technology Stack: Next.js + Vercel

**Decision:** Use Next.js on Vercel for public-facing site.

**Rationale:** Minimal operational overhead. Vercel handles deployment, SSL, CDN. No server to manage.

**Alternatives considered:** Static site generators (unnecessary complexity for current scope).

**Decided by:** Dr. Yash Bhaskarwar

---

### 2026-05 — Domain: bhaskarwar.co.in

**Decision:** Primary domain is bhaskarwar.co.in with www canonical.

**Rationale:** Establishes institutional identity with Indian domain extension appropriate for Maharashtra-based operations.

**Decided by:** Dr. Yash Bhaskarwar

---

### 2026-05-12 — Operational Repository Structure

**Decision:** Establish flat top-level directories (core, parcels, tenants, operations, docs, prompts, branding, infra, archive) as the primary organizational structure.

**Rationale:** Institutional clarity. Each directory maps to a real operational domain. No speculative nesting.

**Alternatives considered:** Single flat docs folder (too undifferentiated as scale grows).

**Decided by:** Dr. Yash Bhaskarwar
