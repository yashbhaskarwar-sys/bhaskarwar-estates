# archive/

**Purpose:** Superseded documents retained for reference.

Documents move here when they are no longer active but should be preserved for institutional memory.

## What Goes Here

- Superseded versions of operational documents
- Deprecated configurations (retained for audit purposes)
- Historical records

## What Does NOT Go Here

- Deleted content — if something is truly obsolete and has no historical value, remove it entirely
- Active documents — those stay in their source directory

## Organization

Prefix archived files with the date they were archived: `2026-05_old-readme.md`

## Access

Archive files are read-only in practice. If you need to restore something from archive, copy it to the appropriate directory and update it rather than editing the archive copy.
