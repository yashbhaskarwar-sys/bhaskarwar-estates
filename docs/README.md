# docs/

**Purpose:** Reference documentation, research, reports, and external materials.

This directory holds informational material that informs decisions — market research, regulatory references, reports from third parties, technical references.

## What Goes Here

- Market research notes
- Regulatory references (zoning, building codes)
- External reports and studies
- Technical references used in planning
- Legal reference notes (not agreements — those go in `tenants/`)

## What Does NOT Go Here

- Internal operational records → `operations/`
- Parcel documentation → `parcels/`
- Tenant files → `tenants/`
- Governance documents → `core/`

## Organization

Use descriptive filenames. Prefix with date where relevant: `2026-05_wani-commercial-market-notes.md`
