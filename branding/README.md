# branding/

**Purpose:** Visual identity guidelines and brand assets.

This directory holds the brand documentation for Bhaskarwar Estates — the visual and verbal identity that represents the estate publicly.

## Current Identity (as established)

| Element | Value |
|---------|-------|
| Primary typeface | Cormorant Garamond (serif) |
| Mono typeface | Geist Mono |
| Background | `#080808` (near black) |
| Primary text | `#e8e4dc` (warm off-white) |
| Accent / gold | `#c9a96e` |
| Muted text | `#a8a8a0` |
| Tone | Dark, minimal, institutional |

## What Goes Here

- Brand guidelines document
- Logo files and usage rules
- Color and typography specifications
- Photography and visual direction notes
- Approved wordmark files

## Critical Rule

Do not redesign the brand without a formal decision logged in DECISIONS.md. The current identity is deliberate and should be treated as stable.
